# 元荃古道：石龍拱 ➔ 深井

新手行山助手。由荃灣港安醫院上元荃古道，經石龍拱，可以原路折返（方案 A），或者跟路牌落到深井食嘢（方案 B）。

內容跟 YouTube《【香港山徑】從「石龍拱」到深井｜元荃古道》嘅路線講法：路牌字眼、頭段樓梯、清快塘要轉「深井」、撤退同埋深井美食。進度、方案同執袋清單會存在手機 `localStorage`。

## 加咗嘅功能

- 每個站點有「喺 Google Maps 開啟位置」。座標來自公開地圖，涼亭同觀景台係參考位置，到埗以現場路牌為準。
- 離線路線示意同海拔剖面，唔使上網都睇到頭段樓梯最斜，以及之後落到深井。
- 日間、陽光高對比、深色三個畫面模式。石龍拱猛烈陽光用「陽光」。
- 實況導航頂部顯示香港天文台即時天氣：荃灣可觀同城門谷氣溫、荃灣雨量、濕度、紫外線、今日預測同天氣警告。每 10 分鐘更新。
- 日落頁：揀時間同站點，用晴空天文估算計趕唔趕得切。三橋日落只計石龍拱涼亭同觀景台，行山用慢行時間。山脊同雲會擋到個太陽。
- 深井食頁：保留起點交通、米線、豬扒麵同回程巴士，另列裕記（深康路 9 號）同兩間分開嘅陳記。能記未核到地址就唔寫。開門時間出發前再確認。
